## Files Generated

The scraper generates multiple report formats:

1. **`young_platform_analysis_[timestamp].json`** - Complete analysis data in JSON format
2. **`young_platform_analysis_[timestamp]_executive_summary.txt`** - Executive summary report
3. **`young_platform_analysis_[timestamp]_social_media_audit.csv`** - Social media metrics and analysis
4. **`young_platform_analysis_[timestamp]_competitive_analysis.csv`** - Competitor benchmarking data
5. **`young_platform_analysis_[timestamp]_partnership_analysis.txt`** - Partnership opportunities analysis
